対象: [tomtomvx/cpp05-09](https://github.com/tomtomvx/cpp05-09) で CPP05 に着手している tvaroux。  
言語: 日本語。完成例は載せない。疑似コードとスケルトンだけを示す。

## 使い方

1. `CPP05_テーマと発展.md` を読む（CPP04 の橋渡しを含む）。
2. 各 exercise について、**事前クイズ → 解説 → 事後クイズ → 自分で実装** の順にする。
3. クイズの模範回答は `<details>` の中にある。先に自分で書いてから開く。
4. 分からない問題は `?` と書いて先に進み、解説の該当節に戻る。
